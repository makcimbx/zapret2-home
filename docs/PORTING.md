# Перенос и безопасная адаптация

Это извлечённый из частного развёртывания проект, не универсальный установщик. Рабочий частный экземпляр не меняется при подготовке Git. В публичной копии используются документальные адреса RFC 5737:

- `192.0.2.1/32` в `files/usr/libexec/zapret2-home-ctl` — **пример исключаемого VPN endpoint**, а не настоящий сервер. Замените на реальные исключения перед включением перехвата; не удаляйте защиту вслепую.
- `192.0.2.2` в `files/usr/lib/zapret2-home/profiles.uc` **и `src/stun-probe.c`** — **пример ожидаемого прямого WAN IPv4** для строгого доказательства маршрута TCP/QUIC/STUN. Меняйте оба места согласованно и пересобирайте STUN helper. Пока адрес не откалиброван, диагностические успехи должны отвергаться. Не превращайте проверку в безусловный успех.
- `192.168.1.20/32` в начальном UCI-конфиге — пример выбранного LAN-клиента, не автоматический поиск устройства. Портируйте до запуска.

Соответствующие fixture-данные используют те же примеры. Исторические IP, приватные сессии, снимки конфигураций и отчёты владельца в Git не включены. Публичные адреса фиксированных тестовых ресурсов сохранены как часть тестового каталога.

## Что проверить на стенде

- OpenWrt 24.10 с `opkg`, AArch64 Cortex-A53, rpcd/ucode, nft/NFQUEUE, procd, curl и CA bundle.
- Интерфейс `network.interface.wan`, мост `br-lan` и существующий conntrack accounting. Скрипты не включают глобальный sysctl за пользователя.
- Совместимость mark-битов `0x00100000`, `0x00200000`, `0x40000000`, conntrack mark `0x005a1723`, приоритетов nft, очередей 213/214 и портов диагностики 12600–12659 с вашим firewall/VPN. Нельзя считать эти значения универсальными.
- Наличие подходящих Lua и бинарников с проверенными хешами, возможность запуска на целевой libc/kernel.
- Актуальность TLS, содержимого, хешей и IP фиксированных ресурсов: устаревшая цель не должна становиться доказательством успеха.

Сначала устанавливайте остановленным с выключенным автозапуском, затем тестируйте одного явно выбранного клиента и ограниченные публичные цели. Изменение сетевой калибровки требует повторного аппаратного теста и проверки VPN. Не расширяйте область до всего LAN для простой проверки сборки.

Установка/обновление могут кратко прерывать только собственную службу. При recovery-required сохраните блокировку и данные восстановления; не удаляйте весь `/var/run/zapret2-home` и не выполняйте глобальный `nft flush ruleset`. Полная перезагрузка/firewall restart — отдельное согласованное испытание.
