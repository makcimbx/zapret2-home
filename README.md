# zapret2-home

Собственный интерфейс LuCI и ограниченный сервис OpenWrt для [zapret2](https://github.com/bol-van/zapret2).
Настройки, управление службой, списки подсетей и сравнение фиксированных профилей TCP, QUIC и UDP — без произвольных shell-команд из браузера.

> **Исходники, не готовая универсальная прошивка.** База — локальная версия 0.4.5 для OpenWrt 24.10 / `aarch64_cortex-a53`. Бинарники и IPK не публикуются: условия распространения статически связанных зависимостей ещё не закрыты. Сборка требует отдельно подготовленные runtime-файлы. Адреса частного развёртывания заменены примерами; перед установкой нужна адаптация, см. [перенос на другой роутер](docs/PORTING.md).

## Возможности

- Нативные вкладки **Настройки**, **Диагностика**, **Профили**, **Журнал**.
- Явный выбор всех LAN-устройств или отдельных клиентов; ручные IPv4-подсети и фиксированные источники списков.
- Независимый выбор Off/профиля для TCP/443, QUIC/443 и ограниченного UDP; шесть вариантов в каждой группе.
- Изолированное сравнение профилей, прогресс и ручное применение. Тест не переключает рабочий профиль автоматически.
- Валидация на backend, узкие ACL rpcd, блокировки операций, транзакционное применение и проверяемый откат.
- Отдельная nftables-таблица и очереди с bypass. Глобальный firewall, VPN, DNS, MTU и offload не перенастраиваются.

На свежей установке служба остановлена, автозапуск выключен; QUIC/UDP по умолчанию выключены. Обновления сохраняют существующую область действия и настройки. Работающий процесс не доказывает доступность приложения.

```sh
node --test tests/frontend.test.js
```

После подготовки runtime-файлов и зависимостей:

```sh
python3 build.py
python3 tests/backend_release_local.py
```

Сборка пишет IPK и манифесты в игнорируемый `dist/`, не обращаясь к роутеру. Это собственный упаковщик IPK, **не** пакет для OpenWrt SDK/feed; другие архитектуры и менеджеры пакетов не заявлены.

## Установка

Сначала адаптируйте сетевые предположения и проверьте зависимости на отдельном стенде. LuCI открывается по пути `/cgi-bin/luci/admin/services/zapret2home`, используется обычная авторизация роутера.

`install.py` / `install_live.py` — специализированные SSH-инструменты обслуживания с проверками состояния. Они не входят в локальный тестовый запуск; не запускайте их на незнакомом роутере. Старые контроллеры без admission-ABI ими намеренно не обновляются. `opkg install` на работающем экземпляре не заменяет защищённую процедуру обновления.

## Структура

- `files/` — дерево устанавливаемых файлов: LuCI, RPC/ACL, procd, ucode, каталоги и лицензии.
- `src/` — исходник ограниченного STUN-клиента.
- `tests/` — unit/fixture/browser-проверки и отдельно обозначенные аппаратные сценарии.
- `build.py`, `runtime-pins.json` — сборка и фиксированные SHA-256 внешних runtime-файлов.
- `docs/` — сборка и перенос.

## Ограничения

Только IPv4 и заданные протоколы/порты; обычный трафик самого роутера не обрабатывается. IP-списки не являются доменными правилами и не меняют маршруты VPN. DPI-обход не меняет страну внешнего IP. Успех загрузки картинки YouTube/CSS Discord или ответа STUN не означает видео/звонок. Фиксированные внешние цели могут устаревать; несовпадение хеша не доказывает DPI-блокировку.

Опубликованная копия проверяется локально; это не утверждение о её установке, аппаратной совместимости, перезагрузке роутера или длительной работе приложений. Логи домашней сети и история установок не публикуются.
